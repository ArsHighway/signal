# Проверка прототипа — 6 ноября 2026

Проверена локальная сборка для macOS Apple Silicon.

## Успешные автоматические проверки

- `npm run build`: отдельная проверка TypeScript и production-сборка Vite.
- `go build ./cmd/server`: сборка сервера на установленном Go 1.23.5.
- `go test -race -v ./...` с настоящей отдельной PostgreSQL: 7 тестов, все пройдены, гонок данных не обнаружено.
- `bash -n` для скриптов запуска и сборки.
- HTTP `/api/health`: статус `ok`, режим `training`.

Тесты проверили идемпотентность после закрытия случая (включая запросы, переиспользовавшие активную тревогу), конкурентное создание, конкурентное принятие, восстановление отложенного действия, отмену, сохранение снимка карточки, роли и сеансы, запрет запросов записи с постороннего сайта, выдачу пропущенных событий и отбрасывание устаревшей геолокации.

## Проверка через интерфейс браузера

1. Вход учебным пользователем и диспетчером в разных вкладках.
2. Ручной SOS: обращение появилось у диспетчера.
3. Принятие и закрытие учебного случая.
4. Подтверждённый статус сохранился после перезагрузки пользовательской страницы.
5. Редактирование и сохранение учебной карточки.
6. Автоматический переход по истечении 15 секунд ожидания.
7. Отмена тревоги и ответ «Я в порядке».
8. Ширина содержимого совпала с шириной экрана при 328 и 1280 CSS px; горизонтального переполнения страницы нет.

Снимок проверенного интерфейса: `preview.jpg`. На нём учебная история, созданная во время проверки. При первом запуске поставляемая база создаётся заново и история будет пустой.

## Не проверялось

Docker-сборка (Docker Desktop не был запущен), настоящая геолокация пользователя, реальные Android/iPhone, работа после блокировки или закрытия браузера, интеграция с экстренными службами. Реальные звонки и уведомления не выполнялись.
